# LARMS v2 — ভূমি অধিগ্রহণ ও হুকুমদখল ব্যবস্থাপনা
Laravel 11/12 + Angular 18 + MySQL · স্থাবর সম্পত্তি অধিগ্রহণ ও হুকুমদখল আইন, ২০১৭ ও বিধিমালা, ২০২৬ · **"LARMS software workflow (Updated Oct 12, 2026)" স্ক্রিপ্টের ৩১ ধাপ + আপত্তি-প্রবাহ**

## ইনস্টল (Windows + XAMPP, ৩ ধাপ)
1. XAMPP Control Panel থেকে **MySQL** চালু করুন।
2. **`install.bat`** ডাবল-ক্লিক করুন (ডিফল্ট: ইউজার `root`, ফাঁকা পাসওয়ার্ড, ডাটাবেস `larms`)। এটি PHP এক্সটেনশন চালু করে, ডাটাবেস বানায়, Laravel তৈরি করে (শুধু `composer create-project`, **অতিরিক্ত কোনো প্যাকেজ লাগে না**), কোড ও তৈরি-করা ইউজার ইন্টারফেস কপি করে, টেবিল ও সিড ডাটা তৈরি করে এবং ওয়ার্কফ্লো সেলফ-টেস্ট চালায়।
3. **`start.bat`** — ব্রাউজারে **http://127.0.0.1:8000/** খুলবে (Node.js লাগে না)।

প্রয়োজন: PHP 8.2+, Composer, ইনস্টলের সময় ইন্টারনেট। `check.bat` = সেলফ-টেস্ট ও সাম্প্রতিক এরর লগ; `reset-database.bat` = সব ডাটা মুছে নতুন করে শুরু।
সেলফ-টেস্ট: `php artisan larms:check` (ডাটাবেস, সিড, রুট, ফ্রন্টএন্ড, ক্ষতিপূরণ হিসাব) · `php artisan larms:simulate` (স্টেপ ০২–৩১, দাবি, ক্ষতিপূরণ আবেদন, আপত্তি — ৩৮টি পরীক্ষা)।

## স্ক্রিপ্ট ধরে পরীক্ষা (UAT) — কোন ধাপে কী করবেন
1. **ধাপ ০১ (RB):** লগইন → *অধিগ্রহণ আবেদনসমূহ* → ডেমো খসড়া আবেদনটি (স্ক্রিপ্টের প্রকল্প ও ৫টি দাগসহ) খুলে **সম্পাদনা**। ৫টি ট্যাব: প্রকল্পের তথ্য → ভূমি ও নকশা → অনুমোদন ও ছাড়পত্র → আর্থিক ও অঙ্গীকারপত্র → রিভিউ ও সাবমিট। সংযুক্তি আপলোড করুন (দ্রুত পরীক্ষায়: `php artisan larms:demo-attach` সব বাধ্যতামূলক সংযুক্তিতে ডামি ফাইল বসায়) → **দাখিল**।
2. **০২ ডিসি → ০৩ এডিসি → ০৩.১ এলএও** (কানুনগো নির্বাচন) → দুই শাখা একসাথে: **সংযুক্তি** (কানুনগো → সার্ভেয়ার → কানুনগো) এবং **চ-ফর্ম** প্রতি উপজেলায় (এসি ল্যান্ড → ইউএলএও → কানুনগো → [সার্ভেয়ার → কানুনগো] → এসি ল্যান্ড) → সব শাখা শেষ হলে এলএও-র **ধাপ ৫**।
3. **৫.২ সংশোধন:** এলএও "সংশোধনের জন্য প্রেরণ" → RB আবেদন সংশোধন করে "সংশোধিত আবেদন দাখিল" → এলএও শুধু সংশ্লিষ্ট উপজেলা এসি ল্যান্ডে পাঠায় → আবার ধাপ ৫।
4. **০৬ ডিসি → ০৭.১/০৭.২ এডিসি** (কমিটি, ১৭ বিষয়ের প্রতিবেদন) **→ ০৮.১–০৮.৪ ডিসি** (সভা, কার্যবিবরণী, প্রাথমিক সিদ্ধান্ত) **→ ০৯ এলএও** (দাগভিত্তিক ছবি/ভিডিও) **→ ১০ ডিসি** (এল.এ কেস নং স্বয়ংক্রিয়: `LA-SYL-01/2025-26` ধরনের)।
5. **১১ এলএও ৪(১) নোটিশ → ১২.১ ডিসি অনুমোদন (প্রকাশ + আপত্তির সময়সীমা ১৫ কার্যদিবস) → ১২.২ যৌথ তদন্ত কমিটি → ১৩ এডিসি ফিল্ডবহি** (শ্রেণি পরিবর্তন লাগলে ১৩.১–১৩.৩) **→ ১৪ ডিসি → ১৫/১৬ ৭(১) নোটিশ**।
6. **১৭ নাগরিক:** লগইন (`01817079954`) → *নোটিশ ও আবেদন* → ৭(১) নোটিশে **মালিকানা দাবি** → **১৮ এলএও** যাচাই (সঠিক / ডিসিতে প্রেরণ → ১৯)। দাবি অমীমাংসিত থাকলে ধাপ ২০ সম্পন্ন করা যায় না।
7. **২০ → ২০.১ → ২০.২ এলএও:** মূল্যতালিকার চিঠি → দলিলমূল্য তালিকা (গড় দর) → **প্রাক্কলন ও রোয়েদাদ** (হিসাব সার্ভারে) → **২১ ডিসি** অনুমোদন → **২১.২** জমার চিঠি → **২২ RB** অর্থ জমা (প্রাক্কলিত অঙ্কের কম হলে নেওয়া হয় না) → **২২.১ হিসাব কর্মকর্তা** জমা যাচাই (যাচাই না হওয়া পর্যন্ত ধাপ ২৩ খোলে না; অগ্রহণযোগ্য হলে RB-র কাছে ফেরত)।
8. **২৩/২৪** ৮(৩) নোটিশ → **২৫ নাগরিক** ক্ষতিপূরণ আবেদন (প্রাপ্য অঙ্ক রোয়েদাদ থেকে এনআইডি মিলিয়ে) → **২৬ এলএও → ২৭ ডিসি** বিতরণ → **২৮ → ২৯ → ৩০ → ৩১(a,b,c)** দখল, ফর্ম ১৬, ঘোষণা, গেজেট, দলিল (ফর্ম ১৯) → **মামলা সম্পন্ন**।
9. **আপত্তি:** নাগরিক নোটিশে "আপত্তি দাখিল" → ডিসি সভা নির্ধারণ → শুনানি প্রতিবেদন → **বিভাগীয় কমিশনার** প্রাথমিক সিদ্ধান্ত → ডিসি চূড়ান্ত সিদ্ধান্ত। আপত্তি অমীমাংসিত থাকলে ৮(৩) নোটিশ (ধাপ ২৩) আটকে থাকে।

পূর্ণ ধাপ-তালিকা ও ফর্মের ঘর: `docs/WORKFLOW-STEPS.md`। প্রতিটি ধাপে কার ভূমিকা, কোন ঘর আবশ্যক, কোন বোতামে কোন ধাপ তৈরি হয় — সব `backend-overlay/config/steps.php` ফাইলে (ডেভেলপার সেখানেই বদলাবেন)।

## পেমেন্ট
- **ম্যানুয়াল মোড:** জমা (ধাপ ২২) ও বিতরণ (ধাপ ২৭) এ কর্মকর্তা চালান/লেনদেন নং হাতে লেখেন; কোনো ব্যাংক/iBAS++/bKash সংযোগ **নেই**। জমা "গৃহীত" থাকে, হিসাব কর্মকর্তা যাচাই করলে "যাচাইকৃত" হয়।
- **রেজিস্টার:** মেনু *ক্ষতিপূরণ জমা ও পরিশোধ* — ফিল্টার, মোট অঙ্ক, CSV/Excel ডাউনলোড।
- **গেটওয়ে স্থান:** `app/Services/Payments/` (`PaymentGateway` ইন্টারফেস, `ManualGateway`, `Gateways`)। iBAS++ ইত্যাদির স্পেসিফিকেশন পেলে এখানে নতুন ক্লাস যোগ হবে; `.env` এ `LARMS_PAYMENT_GATEWAY=manual`।

## সততার সাথে সীমাবদ্ধতা (পড়ুন)
1. **Laravel+MySQL এ চালিয়ে দেখা হয়নি।** আমার পরিবেশে Composer ব্যবহার করা যায় না। যা যাচাই হয়েছে: সব PHP ফাইলের সিনট্যাক্স; **ওয়ার্কফ্লো ইঞ্জিন ও ৩১ ধাপ পুরোটা** সাধারণ PHP-তে সিমুলেশন (৩৩ পরীক্ষা পাস); ক্ষতিপূরণ ইঞ্জিনের হিসাব; Angular বিল্ড। অপরীক্ষিত: মাইগ্রেশন/সিডার/API কল। `install.bat` শেষে `larms:check` যা FAIL দেখাবে সেই স্ক্রিন পাঠান — ঠিক করে দেব।
2. স্ক্রিপ্টে ধাপ ৫ শেষে "Step 6 to ADC" লেখা, কিন্তু ধাপ ৬ ডিসির; এখানে সরাসরি ডিসির ধাপ ৬-এ যায়।
3. সম্ভাব্যতা প্রতিবেদনের ১৭ বিষয়ের মধ্যে স্ক্রিপ্টে ছয়টির (৩, ৫, ১১, ১৪, ১৫, ১৭) নাম/নমুনা আছে; বাকি ১১টির শিরোনাম আমার অনুমান — আসল ফরম অনুযায়ী `app/Services/FeasibilityItems.php` সংশোধন করুন।
4. নোটিশ (৪(১), ৭(১), ৮(৩)) সম্পাদনাযোগ্য খসড়া; বিধিমালার ৬৭টি তফসিলের অফিসিয়াল ছাপার ফরম এখনো বসানো হয়নি। উৎসে করের হার (`config/larms.php`) শূন্য — অর্থ বিভাগের হার বসান। আনুষঙ্গিক ব্যয়ের "১ কোটি পর্যন্ত ৩%, তদূর্ধ্বে ২%" ধাপে ধাপে ধরা হয়েছে (সম্পূর্ণ অঙ্কে ২% চাইলে `CompensationService::incidental` এর mode `flat`)।
5. এই সংস্করণে নেই: হুকুমদখল (ধারা ২০–২৮) ও আর্বিট্রেশনের ধাপ (স্ক্রিপ্টে নেই); পুরোনো সংস্করণ (v1) এ ছিল।
6. বিদ্যমান SMS/ইমেইল বার্তা, দ্বি-স্তর যাচাই (OTP), PDF/গেজেট প্রিন্টের Bangla ফন্ট সংযোজন বাকি; নোটিশ ব্রাউজারের প্রিন্ট/PDF দিয়ে ছাপা হয়।
